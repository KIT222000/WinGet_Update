# 🚀 Winget Update & Manager

>Умная утилита для автоматического обновления Windows приложений на базе **winget**
>Работает в интерактивном режиме и не требует каких то скачиваний просто можно выбрать то что хотите обновить и обновляете себе спокойно
>

---

## Для чего этот скрипт?
Каждый человек наверное сталкивался с тем что ему нужно обновить какую то программку или во время работы нужно что то сделать а у вас устаревшая программка ну и приходиться ждать скачивать обновления
Встроенный `winget upgrade --all` как раз таки решает эту проблему, но не советую так как он всё обновляет

**Скрипт дает контроль над всей системой**
- ✅ Позволяет обновлять **все** программы одной кнопкой
- ✅ Если нужны определенные программы стоит написать в файл ( `config/safe_list.txt` ) - это безопасно
- ✅ Если же нужно чтобы программа не трогала какие то программы пишем в файл ( `config/ignore_list.txt`) чтобы не трогало при обновлений
- ✅ Можно выбрать конкретный ID

---

## Возможности
- 🎨 **Цветной интерфейс** - для простоты интерфейса
- 📝 **Логирование** всех действий с точностью до секунды
- 📋 **Расшифровка ошибок winget** - понятные ошибки для понимание проблем
- 🔐 **Автоматические права доступа** - автоматически выдаёт права админа
- ⚙️ **Гибкая конфигурация**-  через простые текстовые файлы
- 📊 **Итоговая статистика** - после каждого запуска: сколько обновлено, пропущено, с ошибками.

## 📁 Структура проекта
```text
WinGet-Updater/
│
├── update_system.bat       # Главный файл (всё ядро)
│
├── config/                 # Подключаемые конфиги (создай вручную)
│   ├── safe_list.txt       # Список программ для режима --safe
│   └── ignore_list.txt     # Программы-исключения (на них не влияет --full)
│
└── logs/                   # Автоматически создаётся после первого запуска
